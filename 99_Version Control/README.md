# Sentinel
Copilot said: Repository for an end-to-end AI-powered test automation workflow.

## Version Control Logs
This folder stores manual change logs for repository updates.

## Logging rules
- Record every repository change in the appropriate subject file.
- Use `99-General-VersionControl.md` for non-subject changes.
- Add a version tag in `vMAJOR.MINOR.PATCH` format for every new entry.
- Use ISO date format (`YYYY-MM-DD`).
